# Revisi v4 — katalog paket tampil di Blogger

Bagian katalog di bawah slider kini memiliki enam kartu paket langsung di HTML `index.html` dan `blogger-theme.xml`. Kartu tetap terlihat apabila JavaScript Blogger tidak berjalan atau dimuat terlambat.

Setiap kartu memiliki tautan langsung ke WhatsApp `081524677335`. Saat JavaScript tersedia, filter, tombol “Lihat pengalaman lainnya”, modal detail, dan katalog dinamis tetap berjalan seperti sebelumnya.

## Memasang perbaikan

1. Di Blogger buka **Tema** dan unduh cadangan tema aktif.
2. Pilih **Pulihkan** lalu unggah `revision-v4/blogger-theme.xml`.
3. Muat ulang beranda dan gulir ke **Find Your Next Blue**.
4. Enam kartu paket harus langsung terlihat di bawah slider.

Pengujian lokal juga dilakukan dengan JavaScript dinonaktifkan: enam kartu dan enam tautan WhatsApp tetap ada.
