# Halaman mandiri Blogger

Tema `blogger-theme.xml` menyediakan header dengan tautan `/p/adventures.html`, `/p/dive-snorkel.html`, `/p/training.html`, `/p/conservation.html`, `/p/consultancy.html`, dan `/p/contact.html` untuk halaman non-beranda.

Di Blogger, buat enam **Pages** dengan slug tersebut. Salin HTML dari file yang namanya sama pada folder ini ke mode tampilan HTML editor Blogger. Gunakan judul yang sesuai. Jangan mempublikasikan sampai halaman uji terlihat benar di ponsel dan desktop.

Source preview mandiri pada root (`adventures.html`, `dive-snorkel.html`, dan seterusnya) memiliki header lengkap untuk pengujian lokal. File pada folder ini hanya isi halaman yang harus ditempel pada Blogger Page.
